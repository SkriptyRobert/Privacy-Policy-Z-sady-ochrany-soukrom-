# Zásady ochrany soukromí

## 1. Sběr a používání osobních údajů
Naše aplikace neshromažďuje, neukládá ani nesdílí žádné osobní údaje uživatelů.  

## 2. Požadovaná oprávnění
Aplikace nevyžaduje žádná citlivá oprávnění, jako jsou:  
- Přístup k mikrofonu  
- Přístup ke kameře  
- Přístup k poloze  
- Přístup k souborům  

## 3. Reklamy a analytika
Aplikace může zobrazovat reklamy prostřednictvím Google AdMob, které mohou používat anonymní údaje pro personalizaci reklam.
